The agent installs Motion-Doc Studio if needed, then runs the Creative Director (`skills/motion-director`): it asks a
few questions with options (duration, aspect, voice provided/generated, images provided/generated, music, style),
researches, rewrites your idea as a professional production prompt, confirms once, and builds. Optional extras you
can add: a GitHub repo name + PAT for delivery, "sample first", attachments (VO, images, reference videos).
