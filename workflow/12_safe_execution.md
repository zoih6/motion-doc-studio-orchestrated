# 12 — Safe Execution, Storage, and Recovery

طبّق هذا الملف قبل التثبيت، البناء، معالجة الصور/الفيديو، الرندر، المتصفح الآلي، أو أي أمر قد يطول.

## قبل المهمة

```bash
python3 tools/preflight_system.py --json
```

الحدود الافتراضية القابلة للتعديل عبر البيئة: ذاكرة متاحة حرجة 250MB، مريحة 600MB، مساحة مشروع مستهدفة 55MB، وحد أقصى تحذيري 128MB. هذه الحدود تخص البيئة الصغيرة؛ لا تفترض أن الذاكرة الكلية تكفي.

إذا كانت الذاكرة الحرجة أو القرص الحرج، أوقف المهام الثقيلة، افحص العمليات، ونظّف الكاش الآمن فقط. لا تحذف مخرجات المستخدم أو ملفات المشروع.

## تشغيل طويل

```bash
tools/run_logged.sh --name render-draft --log-dir /var/tmp/motion-doc-studio/logs -- bash -lc 'COMMAND'
```

الأداة تحفظ PID وملف log وstatus. تابع السجل بـ `tail -f` وافحص العملية بـ `ps`. البطء ليس تعليقًا؛ أوقف فقط بعد غياب السجل وتغير المخرج واستهلاك CPU/الذاكرة لفترة معقولة.

## مساحة العمل المؤقتة

استخدم:

```bash
export TEMP_WORK=${TEMP_WORK:-/var/tmp/motion-doc-studio}
mkdir -p "$TEMP_WORK"/{tmp,cache,logs,previews,parts}
export TMPDIR="$TEMP_WORK/tmp"
export XDG_CACHE_HOME="$TEMP_WORK/cache"
```

لا تضع `node_modules` أو آلاف PNG أو إطارات الفيديو أو cache داخل مجلد المشروع. عالج الصور على دفعات، وصغّرها قبل التحليل، واستخدم streaming أو previews.

## الاختبار المرحلي

1. اختبار وحدة أو ملف واحد.
2. Preview منخفض الدقة/المدة.
3. فحص بصري وسجل.
4. Render كامل في الخلفية.
5. QA ثم تنظيف آمن.

عند الفشل أصلح الملف/المرحلة/الجزء المتضرر فقط، ولا تعِد كل الإنتاج إلا إذا كان التغيير شاملاً.

## checkpoint والتعافي

بعد كل مرحلة:

```bash
tools/checkpoint.sh --stage assets --result success --output assets/manifest.json --next 'build scenes'
```

عند التعليق: لا تبدأ مهمة جديدة، افحص الذاكرة/القرص/العمليات، انتظر التقدم، أوقف العملية العالقة فقط بعد التحقق، نظّف الملفات المؤقتة الآمنة، ثم أعد اختبارًا صغيرًا واستأنف من `docs/PROGRESS.md`.

## قائمة ما قبل الرندر

- الذاكرة والقرص ضمن الحدود.
- لا توجد نسخة مكررة من نفس الرندر.
- الكاش خارج المشروع.
- preview ناجح.
- الأمر يعمل في الخلفية وله log وPID.
- مخرج واضح وقابل للاستئناف.
- لا يوجد secret في command line أو log.
