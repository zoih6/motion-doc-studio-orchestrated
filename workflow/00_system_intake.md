# 00 — System Intake

## الهدف

تحويل أي فكرة عامية أو ناقصة إلى قرار إنتاج واضح دون إرهاق المستخدم بأسئلة تقنية.

## الجولة الوحيدة

اسأل فقط ما لا يمكن استنتاجه، وبخيارات قصيرة:

1. **المنصة والمقاس:** 9:16، 16:9، 1:1، أو 4:5.
2. **المدة:** اتبع طول الصوت إن وجد؛ وإلا 15/30/60 ثانية أو مدة يحددها المستخدم.
3. **الصوت:** ملف موجود، توليد تعليق، موسيقى ونص، أو صامت.
4. **الأصول:** أصول المستخدم، مصادر حقيقية، توليد أصلي، أو موشن جرافيك فقط.
5. **المرجع:** هل المرجع للإلهام والتحليل فقط؟ ما الذي يُمنع نقله؟
6. **التسليم:** معاينة أولًا؟ GitHub؟ حقوق/علامة تجارية يجب احترامها؟

لا تسأل عن FPS أو الخطوط أو easing أو codecs؛ هذه قرارات النظام. إذا قال المستخدم «قرر أنت»، سجّل ذلك كتفويض. وإلا توقف عند بوابة الاختيار قبل التوليد أو البرمجة.

## المخرجات قبل التنفيذ

أنشئ:

- `docs/brief.md`: ملخص الطلب والجمهور واللغة والمنصة.
- `docs/production_prompt.md`: prompt مهني يتضمن thesis، beats، assets، motion grammar، sound، QA، والممنوعات.
- `docs/decision-log.md`: كل قرار، مصدره، هل هو من المستخدم أم افتراض، وتاريخ القرار.
- `docs/research.md`: الادعاءات والمصادر، إن كان البحث مطلوبًا.
