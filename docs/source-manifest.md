# Source Manifest

هذه النسخة مستقلة التشغيل. تحتوي على مهارات الإنتاج، المحرك، القواعد، الأدوات، والتكاملات المرجعية الموجودة داخل هذا المستودع.

التكاملات الموجودة في `resources/integrations/` محفوظة مع ملفات الترخيص الخاصة بها، ولا تُقرأ تلقائيًا إلا عند اختيار مسار الإنتاج المناسب. لا يعتمد التشغيل على مستودع آخر أو على مسار خارجي.

يجب أن تبقى بيانات الاعتماد والأسرار خارج Git وخارج ملفات المشروع.
