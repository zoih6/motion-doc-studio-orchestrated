# Shot-card index — 124 vendored shot recipes (English) · فهرس بطاقات اللقطات

Source: `resources/skills/shotcraft-shot-cards/` (video-shotcraft, **Apache-2.0**, cards written in Chinese with exact frame timings, curves and layout numbers).
This index gives each card an English one-liner so an agent can find the right one, then open the card for the numbers (`时长` = duration, `能量` = energy, `动效核心` = motion core, `意图` = intent).
Port to this engine with [motion_recipes.md](motion_recipes.md) (moves), [effects_dictionary.md](effects_dictionary.md) and `fx.js`. Re-implement the technique; never copy brand content (see the cards' ATTRIBUTION.md).
