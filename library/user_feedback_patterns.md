# What clients asked for and rejected (learned on the Thuluth film, 3 iterations)

| Feedback (paraphrased) | What it really means | What to do by default |
|---|---|---|
| "I don't want image animation / slideshow / cuts" | Ken Burns photos + crossfades read as cheap | Every shot = objects that build/act; physical transitions |
| "Real VOX-style motion graphics" | Paper, cut-outs, highlighter, measured reveals, editorial rhythm | Motion vocabulary + 2–4 s idea cadence |
| "Don't copy the reference scenes literally — innovate" | Take the grammar, invent topic-specific ideas | Core metaphor from inside the topic |
| "Show me a sample first" | They want control before the long render | 20–60 s sample in final style, then the rest |
| "Use real, content-consistent, high-res assets; not random/unrealistic" | Authenticity matters more than polish | Real artefacts first; AI only for gaps; ≥2× resolution |
| "Character portraits and real clippings" | People + documents make history human | Portrait beats with name blocks; real manuscript crops |
| "Adopt the style of these images" | Match palette/surfaces/light/portrait treatment | Reference analysis → style bible → style frame |
| "More fluid, organised, attractive motion; correct sizing; content clear; not crowded" | Density + legibility + consistent springs | Density rule, TS 1.3, 3 motion presets |
| "Work → render → test → verify before uploading" | Don't ship unchecked work | Critique loop + QA gates, report what was verified |
| "Upload everything to GitHub in batches; keep the workspace clean" | Their workspace is small; GitHub is the archive | Render in /var/tmp, upload parts, delete local files |
| "Did you finish?" (asked repeatedly) | They can't see progress/links clearly | Short status: ✅ done + links + open the video in the viewer |
| "Wow, amazing" after v3 | Sepia manuscript cinema + real artefacts + clean density works | Use it as the default for heritage topics |
