# Integrated Reference Skills

هذه المجلدات snapshots مرجعية غير معدلة. لا تعدّل ملفاتها لإصلاح سلوك المنظومة؛ أضف قواعد التنسيق في `skills/motion-system-orchestrator/` أو `workflow/` ثم اقرأ المرجع المناسب عند الحاجة.

`paper-collage-video` يقدّم Gate 0/Gate 1 وعقود الأصول ومسارات Remotion/Seedance. `vox-motion-graphics` يقدّم Visual State Delta، storyboard، عقود التنفيذ، والنقد التحريري/التقني. `remotion-dev-skills` يقدّم إرشادات Remotion الرسمية للتكوين والحركة والصوت والكابتشن والرندر.

الترتيب المقصود هو: orchestrator → قرار route → skill المتخصصة → validator/QA. عند التعارض، لا تخلط القواعد داخل الملفات المرجعية؛ سجّل قرارًا في `docs/decision-log.md`.
