# Reference Analysis

Use this reference when the user supplies a video, creator corpus, practice kit, or “make it feel like this” target.

## Segment by visual ideas

Find scene/world changes, composition changes, signature motion, meaningful holds, camera handoffs, and sound-driven hits. Fixed-interval sampling is supplementary, not the segmentation method.

Build contact sheets around:

- entry;
- pre-action;
- defining change;
- payoff/settle;
- exit/handoff.

## Deconstruct decisions

For each segment record:

- semantic job and visual thesis;
- scene family and defining mechanism;
- layer stack and focal path;
- camera and transition logic;
- motion personality and cadence;
- treatment and text role;
- sound events;
- reusable primitive;
- what would fail if copied into another story.

## Classify findings, not whole scenes

- `creator_dna`: a repeated high-level principle across references;
- `technique_recipe`: a reusable implementation move;
- `surface_style`: an optional aesthetic;
- `benchmark_specific`: an exact asset, layout, fact, prompt, coordinate, or timing.

A scene may contain several classifications. Promote only repeated, transferable findings. One clever shot is not creator DNA.

## Translate to the new story

Ask:

- Does the new beat have the same relationship geometry?
- Which mechanism is transferable?
- Which material world, assets, and hierarchy must change?
- Is the user asking for mechanism, mood, surface style, or some combination?

Use the reference to improve decisions, not to reproduce its sequence or redistribute its assets.


## Remove the Name After Translation

Once the useful grammar is extracted, production direction should describe observable decisions: focal hierarchy, camera path, material behavior, cadence, transitions, typography role, and evidence treatment. Creator/channel names are weak implementation instructions and can pull an agent toward surface imitation. Keep names only in the analysis record or when the user explicitly wants them as shorthand.
